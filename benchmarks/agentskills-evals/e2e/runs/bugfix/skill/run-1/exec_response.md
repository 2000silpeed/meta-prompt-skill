금액이 가끔 틀리던 원인을 찾아 고쳤습니다. 계산을 전부 Decimal로 바꿨고, 정책 문서대로 사사오입(ROUND_HALF_UP)하고 통화별 자릿수를 씁니다. 증상 예시가 없어서 경계값으로 재현했는데, 새 테스트가 수정 전 19개 실패, 수정 후에는 기존 테스트까지 29개 모두 통과합니다.

## 1. 근본 원인
- **`payment/money.py:8`의 `round(float(value), 2)`**: 모든 반올림이 이 한 줄을 거칩니다. 여기에 결함이 세 가지 있습니다.
  - **float 표현 오차**: 1.005가 실제로는 1.00499…로 저장되어 1.00이 됩니다.
  - **반올림 방식**: Python `round()`는 은행가 반올림(HALF_EVEN)이라 0.125가 0.12가 됩니다. 정책(`docs/PAYMENT_POLICY.md:4`)은 사사오입입니다.
  - **자릿수 하드코딩**: 통화와 관계없이 2자리로 반올림해서 KRW 1234.5가 그대로 남습니다.
- **같은 원인의 다른 위치**:
  - `money.py:13`, `cart.py:6`: 단가×수량, 금액×세율을 float로 곱합니다. 예를 들어 0.145×3이 0.43499…가 되어, 반올림 함수를 고쳐도 결과가 틀립니다.
  - `cart.py:14-19`: 합계를 float로 누적합니다.
- **별도 원인**: `money.py:18-19` 분할 결제는 나머지를 나눠 주지 않아서 10.00을 3으로 나누면 [3.33]×3, 합계 9.99가 됩니다. 정책 7행 위반이라 함께 고쳤습니다.

## 2. 변경 파일
- **`payment/money.py`**:
  - `to_decimal`: float는 `repr` 문자열을 거쳐 Decimal로 바꿉니다(`Decimal(1.005)` 직접 생성은 쓰지 않음).
  - `round_decimal`: `CURRENCY_DECIMALS`로 통화별 자릿수를 정하고 사사오입합니다. 모르는 통화가 오면 `ValueError`를 냅니다.
  - `split_amount`: 최소 단위 정수로 나눈 뒤 나머지를 앞 순번부터 1단위씩 더합니다. 음수 금액도 처리하고, `parts`가 0 이하이면 `ValueError`를 냅니다.
- **`payment/cart.py`**: 단가×수량, 할인, 세금, 합산을 모두 Decimal로 계산하고 마지막에만 float로 바꿉니다.

## 5. 직접 하지 않은 결정과 남은 위험
- **반환형이 아직 float입니다.** 기존 테스트가 `round_amount(10.123) == 10.12`처럼 float와 비교하고, `Decimal("10.12") == 10.12`는 False라서 반환형을 바꾸면 이 테스트가 깨집니다. 기대값은 바꾸지 않았습니다.
  - 지금은 올바르게 반올림한 값을 마지막에만 float로 바꾸므로 `str()`로 찍으면 정확합니다.
  - 그래도 이 값을 받아서 다시 float로 더하거나 곱하는 호출부가 있으면 오차가 다시 생깁니다.
  - 또 float로는 약 9×10¹³ USD를 넘는 금액을 센트까지 정확히 표현할 수 없습니다.
  - **제안**: 반환형을 Decimal이나 정수(최소 단위)로 바꾸는 것입니다. 다만 공개 인터페이스와 `gateway.charge(amount, …)`로 넘어가는 금액 형식이 바뀌므로 결정이 필요합니다.
- **정책 문서에 없는 동작 두 가지**를 새로 정했으니 확인이 필요합니다.
  - 모르는 통화가 오면 오류를 냅니다(기존에는 조용히 2자리로 반올림).
  - 분할 결제는 원금을 먼저 최소 단위로 반올림한 다음 나눕니다.
- **정책과 코드가 맞지 않을 수 있는 부분**: 정책의 "장바구니 합계는 줄 합계의 합"을 줄마다 할인·세금을 적용한 뒤 합산하는 것으로 해석해 기존 구조를 유지했습니다. 영수증 하단에서 세금을 한 번에 계산하는 방식과는 결과가 다를 수 있습니다.
- **확인하지 못한 경로**: 이 저장소에는 DB, JSON 직렬화, ORM 코드가 없어서 저장·전송 경로에서 float로 바뀌는 지점은 확인할 수 없었습니다. 실제로 이 모듈을 쓰는 서비스 쪽에서 따로 점검해야 합니다.
