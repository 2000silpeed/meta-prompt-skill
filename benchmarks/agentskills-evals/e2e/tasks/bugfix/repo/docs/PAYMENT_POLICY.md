# 결제 금액 정책

- 모든 금액은 통화의 최소 단위로 표시한다. 소수 자릿수: KRW·JPY 0자리, USD·EUR 2자리.
- 반올림은 사사오입(ROUND_HALF_UP, 0.5는 0에서 먼 쪽)으로 한다. 은행가 반올림을 쓰지 않는다.
- 장바구니: 각 줄 금액(단가×수량)을 반올림하고, 할인 → 세금 순서로 적용한다.
  할인 금액과 세금 금액은 각각 반올림한다. 장바구니 합계는 줄 합계의 합이다.
- 분할 결제: 나눈 금액의 합은 원래 금액과 정확히 같아야 한다. 나머지(최소 단위)는 앞 순번부터 1단위씩 더한다.
- 환불 금액도 같은 반올림 규칙을 따른다.
