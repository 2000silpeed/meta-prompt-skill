첨부한 제품 사진에서 배경만 교체해줘.

[절대 유지]
- 유리병은 원본 그대로 유지: 모양, 비율, 크기, 윤곽, 병뚜껑, 유리의 투명도와 색, 안에 든 음료 색까지 바꾸지 마.
- 라벨은 픽셀 단위로 원본과 같게 유지: '제주 감귤 에이드' 글자의 철자, 글꼴, 굵기, 크기, 색상, 자간, 위치를 하나도 바꾸지 마. 글자를 다시 쓰거나 다시 그리거나 번역하지 말고, 라벨의 다른 그래픽과 문구도 그대로 둬.
- 병의 위치, 각도, 화면 안 크기, 카메라 시점도 원본과 같게 유지.

[배경 변경]
- 화창한 여름 해변으로 바꿔줘: 밝은 하얀 모래, 청록색 바다, 부드럽게 밀려오는 파도, 맑고 파란 하늘.
- 병은 모래 위나 밝은 나무 테이블 위에 자연스럽게 놓인 모습으로.
- 배경은 얕은 심도로 살짝 흐리게(보케) 처리해서 제품에 시선이 가게 해줘.
- 조명은 오후의 따뜻한 햇살로. 배경 조명에 맞춰 병 아래에 자연스러운 그림자와 바닥 반사를 넣고, 유리에 은은한 하이라이트만 더해줘. 이때 라벨 글자는 가리거나 왜곡하지 마.

[스타일]
- 고급 음료 광고 같은 사실적인 제품 사진, 고해상도, 선명한 초점.
- 소품(야자수 잎, 감귤 조각 등)을 넣는다면 병 뒤쪽에 작게만 두고 병과 라벨을 가리지 마.
- 병 외에 새로운 글자, 로고, 워터마크는 추가하지 마.
