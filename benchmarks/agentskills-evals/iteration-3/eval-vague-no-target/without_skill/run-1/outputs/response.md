작업 폴더가 비어 있고, 어떤 프롬프트를 원하시는지에 대한 정보가 없어서 바로 써드리기 어렵습니다. 아래 몇 가지만 알려주시면 바로 쓸 수 있는 프롬프트로 만들어 드릴게요.

**꼭 필요한 것**
1. **용도**: 이 프롬프트로 무엇을 하려고 하시나요? (예: 블로그 글 쓰기, 코드 리뷰, 고객 문의 답변 봇, 이미지 생성, 데이터 분석 등)
2. **기존 초안**: 이미 쓰신 프롬프트가 있다면 붙여 주세요. 처음부터 쓰는 것보다 다듬는 쪽이 더 정확합니다.

**있으면 더 좋은 것**
3. **어디에 쓰나요**: ChatGPT나 Claude 채팅창에 직접 입력, API 시스템 프롬프트, 에이전트나 자동화 워크플로, 이미지 생성기(Midjourney 등)
4. **결과물 형태**: 길이, 형식(표, JSON, 글머리표, 문단), 말투, 언어
5. **문제점**: 지금 결과에서 마음에 안 드는 점 (너무 길다, 지시를 무시한다, 말투가 어색하다 등)

---

정보를 기다리지 않고 바로 써 보시려면 아래 틀에 내용만 채워서 쓰셔도 됩니다.

```
## 배경
나는 [역할/상황]이고, [목적]을 위해 이 작업이 필요해.
결과물은 [누가] [어디에서] 사용할 거야.

## 할 일
[구체적으로 해야 할 일 한두 문장]

## 입력 자료
<자료>
[원문, 데이터, 코드 등]
</자료>

## 요구사항
- 형식: [예: 표 / 글머리표 / 800자 내외 문단]
- 말투: [예: 친근한 존댓말, 전문적]
- 꼭 포함할 것: [...]
- 피할 것: [...] (이유: [...])

## 좋은 결과의 예시 (선택)
[원하는 결과물 예시 하나]

정보가 부족하거나 애매한 부분이 있으면 추측하지 말고 먼저 질문해 줘.
```

**잘 쓰는 요령**
- 금지 규칙만 나열하지 말고 **이유**를 같이 쓰세요. 이유를 알면 모델이 비슷한 다른 상황에도 맞게 판단합니다.
- 결과를 **누가, 어디에** 쓰는지 알려 주세요. 이걸 알면 수준과 말투가 크게 좋아집니다.
- 예시는 하나보다 **성격이 다른 2~3개**를 주세요. 하나만 주면 그 예시를 그대로 베끼는 경향이 있습니다.

용도나 초안을 알려 주시면 그에 맞춰 완성된 프롬프트로 써 드리겠습니다.
