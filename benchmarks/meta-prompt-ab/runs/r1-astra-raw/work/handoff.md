# 변경 사항

- `shop/clock.py`: 명시적 시간대가 없는 시각을 거부하고 실제 UTC 시각으로 변환합니다.
- `shop/money.py`: bool 수치 입력을 거부합니다. 할인 배분을 정확한 정수 계산과 SKU 오름차순 동률 처리로 수정하고, 누적 취소 기준의 환불 차액을 계산합니다.
- `shop/inventory.py`: 전체 입력과 재고 충분 여부를 먼저 검증하여 실패한 예약이 일부 재고를 차감하지 않게 했습니다.
- `shop/engine.py`: 초기 입력과 snapshot을 깊은 복사합니다. UTC 정규화 및 재귀적 키 정렬로 전체 이벤트 fingerprint를 만들며, 중복 검사를 시간 역행 검사보다 먼저 수행합니다. 이벤트를 복제한 상태에서 처리하고 성공 시에만 반영하여 만료를 포함한 실패 원자성을 보장합니다. 예약 주문만 TTL 경계에서 만료하고, 예약의 부분 취소를 거부합니다. replay는 UTC 시각으로 안정 정렬합니다.
- `tests/test_contract_regressions.py`: 계약의 오류 경로와 경계값을 확인하는 13개 회귀 테스트를 추가했습니다. 원본 계약과 공개 테스트는 수정하지 않았습니다.

# 실제 검증

`python -m unittest discover -s tests -v`를 두 차례 실행했습니다.

1. 코드 수정 직후: 공개 테스트 6개 통과.
2. 자체 회귀 테스트 추가 후: 공개 6개 + 회귀 13개, 총 19개 통과.

회귀 검증에는 큰 정수 할인, 동률 배분, 환불 총액 보존, bool 거부, 재고 원자성, 입력과 snapshot 독립성, 오래된 중복 이벤트, fingerprint의 추가 키와 lines 순서, TTL 경계 실패 복구, 실패 id 재사용, 확인 주문 만료 방지, 예약 전체 취소, UTC replay와 동일 시각 안정 순서가 포함됩니다.

# 한계

평가용 테스트는 제공되지 않아 실행하지 않았습니다. 원자성 구현은 이벤트마다 내부 상태를 깊은 복사하므로 주문과 중복 기록이 커지면 복사 비용이 증가합니다. 다중 스레드·DB·네트워크는 계약 범위 밖이며 구현하지 않았습니다.
