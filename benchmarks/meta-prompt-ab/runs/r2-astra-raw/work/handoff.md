# 변경 사항과 검증

- `shop/clock.py`: 명시적 시간대를 검증하고 UTC로 변환합니다.
- `shop/money.py`: bool 수치를 거부하며, 할인 배분에 정확한 정수 나눗셈과 SKU 오름차순 동률 처리를 사용합니다. 환불은 누적 취소량의 바닥값 차이로 계산합니다.
- `shop/inventory.py`: 모든 재고 충분성 검증을 완료한 뒤 예약 재고를 차감합니다.
- `shop/engine.py`: 입력과 스냅샷을 깊게 복사합니다. 전체 이벤트를 복사본에 적용한 뒤 성공 시에만 반영하여 만료·중복 기록·시간을 포함한 원자성을 보장합니다. UTC 시간과 정렬된 키로 fingerprint를 만들고 중복 검사를 시간 역행 검사보다 먼저 수행합니다. 예약만 TTL 경계에서 만료하며, 예약의 부분 취소를 거부합니다. replay는 UTC 기준의 안정 정렬을 사용합니다.
- `tests/test_regressions.py`: 큰 정수, 할인 동률, 환불 보존, 시간 검증, 재고 원자성, 복사 격리, 중복 정규화, 만료 경계 롤백과 실패 ID 재사용, 확인 후 TTL, 예약 취소, 잘못된 이벤트, replay를 검증하는 12개 테스트를 추가했습니다.

## 실제 검증

`python3 -m unittest discover -s tests -v`를 수정 직후 실행하여 공개 테스트 6개가 통과했습니다. 회귀 테스트 추가 후 같은 명령을 실행하여 전체 18개 테스트가 통과했습니다.

## 한계

평가용 비공개 테스트 결과는 제공되지 않았으며 실행하지 않았습니다. 이벤트 원자성을 위해 내부 상태 전체를 복사하므로 주문 수가 많을 때 처리 비용이 증가할 수 있습니다. 다중 스레드, DB 및 네트워크는 계약상 범위 밖입니다. 원본 계약과 공개 테스트는 변경하지 않았습니다.
