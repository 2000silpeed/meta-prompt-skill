# 변경 사항

- parse_time이 명시적 timezone offset 또는 Z만 허용하고 UTC instant로 변환하도록 수정했습니다.
- 할인 배분 동률을 SKU 오름차순으로 처리하고, 환불 증분을 각 구간의 floor 차이로 계산하도록 수정했습니다.
- 재고 reserve를 사전 검증 후 일괄 차감하도록 고쳐 실패 시 원본 재고가 유지됩니다.
- OrderBook의 입력 fingerprint, 중복 이벤트, 만료 처리, 예약/확정/취소, replay 정렬과 snapshot 깊은 복사를 계약에 맞게 구현했습니다.
- 이벤트 적용은 만료 처리까지 포함해 staged 복사본에서 수행하므로 실패 시 상태가 원자적으로 복구됩니다.

# 실제 검증

- python -m unittest discover -s tests -v (6개 테스트 통과)
- 계약 smoke 테스트: 시간대 동치, 확정 후 부분 취소와 환불, 실패한 취소의 원자성, 환불 계산을 확인했습니다.
