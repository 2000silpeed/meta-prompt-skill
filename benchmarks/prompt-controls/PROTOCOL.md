# 프롬프트 배치와 공통 제어의 제한 실험

사전 고정일: 2026-10-28. 기존 meta-prompt의 수작업 컴파일본과 한 가지 제어를
더한 컴파일본을 비교한다. 목표는 스킬 지시를 늘리는 것이 아니라, 관찰 가능한
오류를 줄이는 추가 지시만 선택하는 것이다. 본문은 결과를 보기 전에 동결한다.

## 조건과 실행 단위

- 현재 체크아웃의 SKILL.md와 과제에 해당하는 카드로 baseline을 구성한다.
  baseline도 목표·맥락·제약·완료 기준을 담고 있으며 일부러 약화하지 않는다.
  카드 전문을 실행 시 다시 읽히는 실험이 아니라 선택한 규칙의 수작업 컴파일본 비교다.
- positioning은 같은 segment 문자열의 순열이다. 나머지 조건은 tip 하나에 관한
  일반 지시 한 문장만 추가한다. 추가 사실·정답·버그 위치·비공개 채점 기준을 넣지 않는다.
- 5개 tip별 과제와 단순 요청·이미지 프롬프트 보존 회귀 과제, 총 7개다.
  각 baseline/candidate를 2회 실행한다. 총 28개의 독립 새 에이전트를 사용한다.
- 요청 모델은 gpt-6-luna, effort=low로 고정한다. 실제 backend 모델/effort를
  도구가 반환하지 않으면 observed 값은 unknown이다. 다른 제공자나 이미지 생성은 실행하지 않는다.
- 각 pair의 첫 arm을 교대하고 두 번째 반복에서는 뒤집는다. 최대 3개를 동시 실행한다.
  작업자는 자기 입력 파일 하나만 읽고 자기 결과 파일 하나만 쓴다. 테스트·정답·다른 실행은 읽지 않는다.
- 배치 요약이 아니라 실제 요청 결과를 수집한다. 질문/계획/완료 주장만으로 성공 처리하지 않는다.
- model, 입력, 컴파일 방법, 제어 문구, 채점 앵커, 실행 순서와 SHA-256은 첫 실행 전에
  evidence.json에 기록한다. 실패한 실행을 조용히 교체하지 않는다.

## 채점 기준

각 과제에 적용되는 축만 0/1/2로 판정한다. 적용 축과 과제별 앵커는 evidence.json에
사전 고정한다. 조건명과 프롬프트 길이를 숨기고 섞은 결과를 별도 에이전트가 채점한다.
작업자 자기평가는 사용하지 않는다. 수치/라벨/원문 보존은 evaluate.py의 독립 검사도 대조한다.

| 축 | 0 | 1 | 2 |
|---|---|---|---|
| task_accuracy | 핵심 결과가 틀림/없음 | 일부 맞지만 중요 누락 | 요구한 핵심 결과가 맞음 |
| evidence_boundary | 사실 날조·근거 없는 단정 | 중요한 가정/한계 구분 누락 | 사실·계산·가정·미확인을 의미상 구분 |
| consistency | 동일 조건에 다른 기준 적용 | 일부 라벨/경계 처리 오류 | 같은 기준·단위·우선순위 일관 적용 |
| completion | 질문·계획에 머물거나 산출물 없음 | 필수 산출물 일부 누락 | 요청한 산출물·검증 가능한 내용 존재 |
| no_overreach | 범위/원문/출력 계약 훼손 | 불필요한 형식·주장 추가 | 사용자 범위와 출력 계약 보존 |

전용 제목/표제어를 썼다는 이유만으로 점수를 주지 않는다. baseline도 의미상 구분하면 만점이다.
토큰 비용을 추정하지 않고 입력·출력의 문자 수만 별도 기록한다. 경과 시간은 참고값이며 모델
속도나 품질 점수로 쓰지 않는다. positioning의 입력 길이는 문자 수만 확인하고 토큰 수로 부르지 않는다.

## 채택 기준

각 tip은 두 반복 모두 적용되는 모든 채점 축이 떨어지지 않고, 주 평가 축의 합계가
baseline보다 2점 이상 높으며, 사실 경계/범위 보존 회귀가 없고, candidate의 독립 수치·라벨·원문 보존 검사를 모두 통과하며, 추가 프롬프트 길이가
20% 이내일 때만 **해당 과제에서 유망한 조건부 지시**로 채택한다. 그 외는 유지/보류한다.
단순 과제는 candidate에서 추가 지시를 생략한다. 이 조건의 입력은 baseline과 같아야 한다.
이미지 과제는 프롬프트 텍스트의 참조 역할·정확한 문구·편집 불변 조건만 평가한다.

두 반복의 native text 실험으로 모든 모델의 최적 순서, 추론 능력 향상, 이미지 품질 향상이나
실제 과금 절감을 입증했다고 말하지 않는다. 일반화하려면 별도 과제·모델의 후속 실험이 필요하다.
점수가 포화되거나 근거가 약하면 스킬 본문을 바꾸지 않는 것도 유효한 결과다.

## 재검사

`python3 benchmarks/prompt-controls/evaluate.py audit`는 사전 고정 해시, 28개 결과의 완전성,
채점 범위, 수치/분류/원문 보존 검사, 채택 판정을 재계산한다. 모델을 다시 호출하지 않는다.
전체 자료와 실제 출력·채점·한계는 evidence.json에 보존한다.
