# 원요청 대 현재 meta-prompt

2026-10-28. 사용자의 직접 비교 요청에 따른 제한된 실험이다. 실사용 스킬은 변경하지 않는다.

## 고정 조건

1. 직전 스트레스 실험의 6개 합성 과제에서 목표·업무 자료·출력 계약만 추출해 원요청으로
   사용한다. 이전 기준본의 공통 메타 지시는 제거하되 업무 요구를 약화하지 않는다.
   추가로 기존 주문·재고 엔진 fixture와 비공개 41개 검사를 재사용한다.
   두 조건에 같은 계약·코드·공개 테스트·도구와 출력 계약을 준다. 이전 모델 출력은 재사용하지 않는다.
2. 변환기는 실제 SKILL.md → registry → 해당 index → 필요한 카드만 읽는다.
   변환기 요청 모델은 양쪽 모두 gpt-6-luna/low다. 실행 타깃은 Luna 또는 Terra로 구분한다.
   원요청·업무 계약만 볼 수 있고 정답·평가기·이전 출력·구현 코드는 볼 수 없다.
3. 변환기는 과제를 풀지 않고 `{SOURCE}`가 정확히 한 번 들어가는 실행 프롬프트 틀만 만든다.
   실행 시 SOURCE는 원요청 원문으로 치환한다. 도메인 사실·정답·의무를 새로 추가하거나,
   내용을 삭제·교체하지 않는다. 출력용 해설·가정·API 권고는 실행 프롬프트와 별도로 보존한다.
   실험 자체의 목표·권한·도구 제한은 양쪽에 동일하게 적용한다.
4. 원요청·정답·코드 fixture·평가 기준을 변환 전에 고정하고, 실제 변환본도 독립 검토 후
   첫 과제 실행 전에 고정한다. 결함 있는 변환본을 결과가 좋아질 때까지 골라내지 않는다.
   결과를 본 뒤 프롬프트를 바꾸지 않는다.
5. 타깃 모델은 gpt-6-luna와 gpt-6.1-terra, effort=low, 각 조건 2회 반복이다.
   6개 텍스트 과제를 한 묶음으로 실행하는 8개 agent와 코드 과제 8개 agent를 새 context로
   실행한다. 총 16개 유효 실행 묶음, 텍스트 48개 결과와 코드 8개 구현이다.
   같은 묶음 안 결과나 검사 항목은 독립 표본이 아니다. 모델 안에서 먼저 비교한다.
6. 최대 동시 작업자 3명. 실행 순서는 조건을 교대하고 반복에서 뒤집는다.
   원요청 작업자는 스킬을 읽지 않고, 변환본 작업자도 변환본 이외의 스킬을 다시 읽지 않는다.
   작업자에게 raw/meta 조건명, 정답, 이전 결과를 주지 않는다.
   양쪽 모두 로컬 표준 라이브러리 Python을 허용하고 외부 API·웹·새 agent·패키지 설치를 금지한다.
   코드 작업은 제공된 임시 작업 폴더만 수정한다. 텍스트 과제는 자기 입력·출력만 읽고 쓴다.
7. 변환 호출 2회와 과제 실행 16회를 계획한다. 용량 부족/입력/수집 장애 복구는 최대 2회.
   원래 실패·복구 이유와 원문을 보존한다. 내용 오답·검사 실패·무결과는 재시도하지 않는다.
   실제 backend 모델·effort·토큰·과금은 도구가 반환하지 않으면 unknown이다.

## 측정과 해석

- 텍스트는 기존 고정 정답에 대해 JSON 키·타입·배열 순서·원문·수치를 검사한다.
  과제 전체 통과와 원자 값 일치를 구분한다. 정답은 양쪽에서 같은 것이다.
- 코드는 각 구현의 비공개 41개 검사 통과 수, 41/41 구현 수, 계약·공개 테스트 보존과
  실제 handoff/완료 기록 유무를 따로 기록한다. 공개 테스트 통과만으로 완료라 하지 않는다.
  실패한 구현도 보존하고 다른 모델의 코드를 섞지 않는다.
- 프롬프트 문자 증가와 변환 호출 수를 별도 표시한다. 토큰/금액을 문자로 추정하지 않는다.
- 두 범주의 점수를 임의 가중 합산하지 않는다. 실용적 이득을 주장하려면 해당 범주에서
  두 모델 각각 비감소, 반복별 회귀 없음, 텍스트는 24칸 중 2칸 이상 증가 또는 코드는
  비교 가능한 164개 검사 중 4개 이상 증가가 필요하다. 형식/원문/권한 손상도 없어야 한다.
  기준 충족도 이 한정 과제에서의 신호이며 통계적 유의성이나 모든 작업의 우수성이 아니다.
- 원요청에는 이미 상세한 계약이 있다. 모호한 실제 사용자 요청·모든 모델·이미지 품질에
  일반화하지 않는다. 비교 범위는 스킬이 생성한 실행 틀 + 불변 원문 대 원문 자체다.
  완전 자유 재작성이나 자동 서비스 전환의 효과는 포함하지 않는다.

`python3 benchmarks/raw-vs-meta/evaluate.py audit`는 모델 호출 없이 점수와 기록을 재계산한다.
