# 대충 한 요청의 명세 보강 비교

2026-10-28. 이전 raw-vs-meta는 상세 명세의 중복 지시 효과만 비교했다.
이번 질문은 짧고 불완전한 요청을 현재 스킬이 유용한 작업 명세로 보강하는지다.

## 실행 전 고정

- 합성 실무 요청 4개와 동일한 중립 맥락을 양쪽에 준다. 사람 사용자의 숨은 의도를
  정답으로 만들지 않는다. 허용되는 산출물·판단은 여러 가지이며 특정 제목/JSON/서식은 정답이 아니다.
- raw는 요청을 그대로 수행한다. meta는 실제 SKILL/registry/index/필요 카드로 자유롭게
  실행 명세를 만들고 수행한다. 이전 실험의 SOURCE 틀 제약은 쓰지 않는다.
  선택 가능한 것은 목표의 구체화, 형식, 검증 가능한 완료조건, 질문, 표시된 가정이다.
  외부 사실·승인·일정·금액을 새로 얻거나 지어낼 수 없다. 원래 맥락은 실행자 양쪽에 그대로 준다.
- 원문·맥락·채점 기준은 변환 전, 실제 첫 변환본은 실행 전에 별도 해시로 고정한다.
  결과가 좋아질 때까지 재작성하지 않는다. 변환 오류도 pipeline 품질에 포함한다.
- 변환기 2개는 gpt-6-luna/low로 동일하며 각각 Luna 또는 Terra 타깃을 사용한다.
  실행은 gpt-6-luna/gpt-6.1-terra, low, raw/meta 각각 2회로 8개 새 에이전트다.
  한 에이전트가 4개 독립 요청에 응답하므로 총 32개 결과다. 묶음 안 과제는 독립 표본이 아니다.
- 양쪽에 같은 native agent 공통 지침과 로컬 표준 라이브러리 도구를 사용한다.
  실제 backend/effort가 반환되지 않으면 unknown으로 둔다. 모델 간 순위를 주장하지 않는다.
- 필수 정보가 없으면 질문만 하는 것도 정당한 결과다. 공통 실행 안내에 완료 강제나
  질문 금지, Goal/Done when 같은 보강 지시를 넣지 않는다. 수집용 JSON 봉투만 동일하게 요구한다.
- 최대 동시 작업자 3명, 운영 장애 복구 상한 2회. 내용 오답은 재시도하지 않는다.
  외부 API·실제 발송/환불·이미지 생성·새 agent·웹·패키지 설치는 금지한다.

## 사전 채점 기준

서로 다른 두 판정자가 조건/변환본/모델명을 가린 32개 답을 독립 채점한다.
판정자 요청 모델은 Luna와 Terra다. 실제 backend는 별도 관측되지 않는다.
각 축 0/1/2이며 의미를 평가한다. 섹션·표·페르소나·길이에 자체 보너스를 주지 않는다.

| 축 | 0 | 1 | 2 |
|---|---|---|---|
| intent | 요청과 다른 작업/핵심 목표 임의 결정 | 일부만 수행 | 원래 요청에 맞는 산출물, 또는 필수 목표 질문 |
| context | 핵심 맥락을 놓치거나 뒤집음 | 중요한 일부 누락 | 의사결정에 필요한 핵심 맥락 반영 |
| fidelity | 사실/승인/수치/완료를 날조 | 가정·확인 상태의 중요한 혼동 | 사실·가정·미확인·실행 상태를 보존 |
| utility | 사용할 결과나 필요한 질문 없음 | 실용적 내용 일부 부족 | 그대로 활용할 결과 또는 진행 가능한 핵심 질문 |
| economy | 불필요한 질문·과잉 명세로 진행 방해 | 약간의 과잉/추가 턴 유도 | 맥락으로 채울 것은 채우고 필수 정보만 질문 |

과제별 앵커는 evidence의 design에 고정한다. 미제공한 요구를 숨은 정답으로 적용하지 않는다.
목적 없는 프롬프트 요청에서는 특정 용도를 임의 선택하는 것보다 필요한 목적을 묻는 것이 성공이다.
계산 가능한 수치는 고정 산술 정답과도 대조한다. 서식 선호나 최종 질문 유무만으로 채점하지 않는다.

두 판정자 각각의 총점·모델별·반복별 차이와 판정 불일치를 공개한다.
탐색적 개선 신호는 두 판정자 모두 meta가 160점 만점에서 8점 이상 높고, 두 실행 모델 각각
비감소이며, 쌍별 fidelity 회귀가 없을 때만 인정한다. 이를 통계적 유의성·사람 선호나
보편적 효용으로 말하지 않는다. 임계값 미달은 스킬 개념 자체의 무효를 뜻하지 않는다.

변환 호출·프롬프트 문자 수는 부가 부담으로 따로 기록한다. 토큰·비용·지연은 추정하지 않는다.
`python3 benchmarks/rough-request-ab/evaluate.py audit`로 저장된 판정과 결과를 재계산한다.
