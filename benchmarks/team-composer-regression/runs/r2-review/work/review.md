# 독립 계약 검토

CONTRACT.md, shop/*.py, 기존 tests/ 및 handoff.md만을 기준으로 검토했다. 다른 실행, 비공개 테스트, 기준 구현, 평가기, 점수는 조회하지 않았다.

## 발견 사항 및 조치

수정이 필요한 계약 위반은 발견하지 않았다. shop 코드와 공개 계약 및 기존 테스트는 수정하지 않았다.

제작자 테스트에서 명시적으로 다루지 않은 모듈 간 경계를 tests/test_review.py에 독립 테스트 5개로 추가했다.

- 여러 예약의 동시 만료 후 후속 이벤트 실패: 모든 만료와 재고 변경이 롤백되며, 같은 실패 id를 성공 이벤트로 재사용하면 만료 재고가 새 예약에 사용됨을 확인했다.
- 0원 SKU와 유료 SKU 혼합 주문: 소진 SKU에 대한 추가 취소 실패가 원자적이며 items 생략 시 남은 SKU만 취소되고 전체 환불과 재고가 보존됨을 확인했다.
- lines 순서 및 중첩 미지 키 변화: 기존 id와 다른 fingerprint로 거부되며 정확한 재전송은 no-op임을 확인했다.
- 할인 잔여 단위: gross가 가장 작은 SKU라도 fractional remainder가 크면 잔여 할인을 받으며 전액 할인도 보존됨을 확인했다.
- 빈 재고와 UTC 동일 시각 replay: 입력 순서를 유지하고 caller 입력을 보존하며 역전된 같은 시각 이벤트는 실패함을 확인했다.

## 실제 실행 결과

- `python3 -m unittest discover -s tests -v`: 총 23개 통과.
- `python3 -m unittest discover -s tests -p test_review.py -v`: 독립 추가 5개 통과.

## 한계

알려진 계약 미충족 사항은 없다. 검증은 공개 계약, 코드 검토, 공개 및 자체 테스트에 한정되며 비공개 평가의 통과를 주장하지 않는다.
